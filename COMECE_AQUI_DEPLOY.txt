## 3️⃣ Passos Rápidos (30 minutos)

### ✏️ Passo 1: Local (5 min)
```bash
cd ~/Projetos/a-feira
git add .
git commit -m "Pronto para deploy"
git push origin main
```

### 🌐 Passo 2: PythonAnywhere (20 min)
1. Crie conta gratuita: https://www.pythonanywhere.com
2. Abra **Bash Console**
3. Execute:
```bash
cd ~
git clone https://github.com/SEU_USUARIO/a-feira.git
cd a-feira
mkvirtualenv --python=/usr/bin/python3.13 a-feira-env
pip install -r backend/requirements.txt
```
4. Configure **Web → Manual → Python 3.13**
5. Edite WSGI (copie de `wsgi_example.py`)
6. Configure Static files (URL: `/` → Dir: `/home/USERNAME/a-feira/frontend`)
7. Clique **Reload**

### 🧪 Passo 3: Testar (5 min)
Visite: `https://seuusername.pythonanywhere.com`
