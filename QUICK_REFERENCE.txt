// ============================================================
// FLUXO DE DADOS
// ============================================================

User Action (Frontend)
        ↓
JavaScript event handler (app.js)
        ↓
Fetch API → POST/PUT/DELETE to backend
        ↓
Flask route (app.py)
        ↓
Database function (database.py)
        ↓
Read/Write JSON file (data/*.json)
        ↓
Response back to frontend
        ↓
Update DOM (renderizar lista)

// ============================================================
// PRINCIPAIS FUNÇÕES JAVASCRIPT
// ============================================================

initTheme()
  └─ Lê localStorage, aplica dark mode se necessário

switchPage(pageName)
  └─ Alterna entre páginas (listas, produtos, lista-detalhe)

loadListas() / loadProdutos()
  └─ Fetch dados da API, renderiza

renderItensLista(lista)
  └─ Cria HTML para cada item, chama calcularTotais

calcularTotais(itens)
  └─ Calcula Total da Lista e Total do Carrinho
  └─ Atualiza valores no DOM

toggleItem(listaId, produtoId)
  └─ PUT /api/listas/<id>/itens/<pid>/toggle
  └─ Marca/desmarca checkbox

updateQuantidade(listaId, produtoId, novaQuantidade)
  └─ PUT /api/listas/<id>/itens/<pid>/quantidade
  └─ Altera quantidade do item


// ============================================================
// PRINCIPAIS FUNÇÕES PYTHON
// ============================================================

def create_produto(nome, categoria, quantidade, unidade, preco_unidade, descricao="")
  ├─ Validação básica
  ├─ Gera ID único (timestamp)
  ├─ Cria dicionário produto
  ├─ Escreve em data/produtos.json
  └─ Retorna produto criado

def get_lista(lista_id)
  └─ Retorna lista com todos seus itens

def add_item_to_lista(lista_id, produto_id, quantidade)
  └─ Adiciona ou atualiza item em uma lista

def toggle_item_checked(lista_id, produto_id)
  └─ Inverte valor de checked (true ↔ false)

def calcularTotais(itens)  [JavaScript]
  ├─ Itera sobre itens da lista
  ├─ Soma todos os valores → Total da Lista
  ├─ Soma apenas checked → Total do Carrinho
  └─ Atualiza DOM

// ============================================================
// PERFORMANCE
// ============================================================

- Cache de produtos em memória (produtosCache)
- Sem N+1 queries (tudo em JSON)
- Fetch síncrono (await) evita race conditions
- Cálculos em cliente (não overhead no servidor)
- Renderização incremental (não re-renderiza tudo)

// ============================================================
// DECISÕES TÉCNICAS PRINCIPAIS
// ============================================================

✓ JSON em arquivo → Simples, sem BD setup, PythonAnywhere-compatible
✓ Vanilla JS → Zero dependências, deploy imediato
✓ Tailwind CDN → Sem build step, fácil customizar
✓ Flask → Leve, fácil, ótimo para MVP
✓ IDs com timestamp → Único, sem sequência DB
✓ Cache em memória → Evita requisições ao buscar
✓ Sem autenticação → MVP - adicionar conforme necessário
